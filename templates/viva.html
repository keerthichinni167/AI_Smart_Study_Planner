🎤 Viva Questions

Important questions and answers for the AI Smart Study Planner project.

🤖 About the Project

The AI Smart Study Planner is a web-based application developed using Python and Flask. It helps students manage subjects, exams, study schedules and academic progress. The system calculates subject priority and generates a personalized seven-day study plan.

🐍 Python & Flask

1. What is Python?
Answer: Python is a high-level, interpreted programming language known for its simple syntax and wide range of libraries.
2. What is Flask?
Answer: Flask is a lightweight Python web framework used to build web applications and APIs.
3. Why did you use Flask in this project?
Answer: Flask is used to connect the frontend with the Python backend, handle routes, process requests and communicate with the MySQL database.
4. What is a Flask route?
Answer: A route maps a URL to a Python function. For example, the /resources route displays the Resources page.
5. What is Jinja2?
Answer: Jinja2 is a template engine used by Flask to generate dynamic HTML pages using Python data.

🗄️ MySQL Database

6. Why did you use MySQL?
Answer: MySQL is used to store student information, subjects, exams, study plans and progress data in a structured relational database.
7. What tables are used in your project?
Answer: The project uses five main tables: students, subjects, exams, study_plans and progress.
8. What is a primary key?
Answer: A primary key uniquely identifies each record in a database table.
9. What is a foreign key?
Answer: A foreign key connects one table with another table using a related key.
10. How does Flask connect to MySQL?
Answer: The project uses the mysql.connector Python library to establish a connection between Flask and MySQL.

🌐 HTML, CSS & JavaScript

11. What is HTML?
Answer: HTML is used to create the structure and content of web pages.
12. What is CSS?
Answer: CSS is used to style web pages, including colors, layouts, spacing, fonts and responsiveness.
13. What is JavaScript?
Answer: JavaScript is used to add dynamic and interactive behavior to web pages.
14. What is a template in Flask?
Answer: A template is an HTML file that Flask renders using Jinja2 to display dynamic information.

🧠 AI & Machine Learning

15. What is Artificial Intelligence?
Answer: Artificial Intelligence is the field of creating systems that can perform tasks requiring intelligent decision-making.
16. Where is AI used in your project?
Answer: AI-based logic is used to calculate subject priority and generate an intelligent study plan.
17. What factors are considered for priority?
Answer: The priority calculation considers exam timing, student performance, subject difficulty and remaining topics.
18. What is Scikit-learn?
Answer: Scikit-learn is a Python machine learning library that provides tools for data processing, modeling and analysis.

📊 Pandas & NumPy

19. What is Pandas?
Answer: Pandas is a Python library used for data manipulation and analysis.
20. What is NumPy?
Answer: NumPy is a Python library used for numerical operations and array-based data processing.
21. Why are data processing libraries useful?
Answer: They help process academic data efficiently and support calculations used by the AI component.

🤖 Project-Specific Questions

22. What is the main purpose of your project?
Answer: The main purpose is to help students organize their studies and generate personalized study schedules based on academic priorities.
23. How does the study planner work?
Answer: It calculates subject priority, identifies remaining topics and distributes study sessions across a seven-day schedule.
24. Why are exam dates important?
Answer: Exam dates help determine how urgently a subject needs to be studied.
25. Why is subject difficulty considered?
Answer: Difficult subjects may require more study attention, so difficulty contributes to the priority calculation.
26. How does the system track progress?
Answer: The system stores study hours, completed topics and progress percentage in the progress table.
27. What happens when a study session is completed?
Answer: The study plan status is updated and the student's completed topics and progress information are updated in the database.
28. How many days does the generated plan cover?
Answer: The current planner generates a seven-day study plan.
29. What happens if a subject has no remaining topics?
Answer: The planner assigns revision and practice instead of remaining-topic study.
30. What are the advantages of your project?
Answer: It provides personalized planning, subject prioritization, progress tracking and reduces manual study-planning effort.

🚀 Future Scope

31. What improvements can be added in future?
Answer: Future versions can include mobile applications, advanced machine learning models, notifications, performance prediction and integration with online learning resources.
32. Can this project be converted into a mobile app?
Answer: Yes. The existing backend can be extended with APIs and connected to a mobile application.

  • Be able to explain the project architecture.
  • Know why Flask and MySQL were selected.
  • Explain how the AI priority score is calculated.
  • Explain how the seven-day study plan is generated.
  • Know the five database tables used in the project.
  • Be prepared to explain the project demo step-by-step.
